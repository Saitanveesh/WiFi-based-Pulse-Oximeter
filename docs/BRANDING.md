# Repository visual identity

This project uses a source-controlled SVG banner at [`docs/brand/pulse-oximeter-banner.svg`](brand/pulse-oximeter-banner.svg).

The banner is a conceptual system diagram, not a photograph of an assembled or validated device. It labels the MAX30100 optical sensor, ESP8266 microcontroller, OLED display, and optional Blynk dashboard. It intentionally contains no invented heart-rate or SpO₂ readings.

**Presentation rule:** Keep system architecture diagrams separate from actual photographs, measured results, and test evidence. Do not present fabricated mobile dashboards or measurement values as observations from a working prototype.

The label *educational prototype* and the non-clinical-use boundary must remain visible while hardware and accuracy testing are pending.
